Interval conventions & off-by-one

The one rule: pick a convention, then never mix it. Every +1, −1, <, <= is forced by that choice.

Bracket notation

  • [a or b] — closed: endpoint included.
  • (a or b) — open: endpoint excluded (stop before it).
  • [low, high) = half-open: low in, high out. The common default.

Only two rows differ (loop test, drop-right). low = mid + 1 is the same in both because low is included in both — you always skip the just-checked mid.

Binary search, both ways

// HALF-OPEN  [low, high)
let low = 0, high = arr.length;      // high excluded
while (low < high) {
  const mid = low + ((high - low) >> 1);
  if (arr[mid] === t) return true;
  else if (arr[mid] < t) low = mid + 1;
  else high = mid;                   // no -1: high was excluded
}
return false;
// CLOSED  [low, high]
let low = 0, high = arr.length - 1;  // high included
while (low <= high) {
  const mid = low + ((high - low) >> 1);
  if (arr[mid] === t) return true;
  else if (arr[mid] < t) low = mid + 1;
  else high = mid - 1;               // -1: high was a real cell
}
return false;

Midpoint (independent axis)

FormVerdict
(low + high) / 2Correct in JS/TS (64-bit floats). Overflows in fixed-int languages.
low + (high − low) / 2Overflow-proof everywhere. Preferred habit. Reads as “step half the gap from low”.

Always Math.floor(...) (or >> 1) — array indices must be integers.

Debug checklist

  • Test the 1-element array first. It fails instantly on any mixed convention.
  • Mixed length−1 + < → skips the last/only element.
  • Mixed length + <= → reads arr[length] = undefined, or infinite loop.
  • Infinite loop → a bound isn’t moving. Check you did +1/−1 on the checked mid.
  • Off-by-one on output → ask “did I include or exclude this endpoint?” and make both bounds agree.

Common half-open idioms

for (let i = 0; i < arr.length; i++)   // [0, length) — every index once
arr.slice(a, b)                        // [a, b)      — b excluded
"abcde".substring(1, 3)  === "bc"      // [1, 3)      — indices 1,2
range(a, b) → a, a+1, ..., b-1         // [a, b)      — b elements: b - a

Half-open’s payoff: length = high − low with no +1, and adjacent ranges [a,b) + [b,c) tile perfectly with no gap or overlap.
